# ✨ Luméra Skincare

A modern luxury skincare website built using HTML, CSS, and JavaScript with a premium beige aesthetic and responsive design.
 Here Its public link-https://lumera-skincare.netlify.app/

## 🌟 Features

* 🛍️ Interactive Product Catalog
* 🔍 Real-Time Product Search
* 📂 Product Category Filtering
* 📊 Product Sorting
* 🛒 Shopping Cart Functionality
* 💰 Indian Rupee (₹) Pricing
* 📱 Fully Responsive Design
* 🎨 Elegant Luxury Beige UI
* 📧 Newsletter Subscription Form
* 📩 Contact Form
* ⚡ Smooth User Experience

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 📌 Current Status

This project is a front-end e-commerce website prototype created for learning and portfolio purposes.

### Implemented

* Product browsing
* Search and filtering
* Cart management
* Responsive layout
* UI/UX design

### Not Yet Implemented

* Real payment gateway integration
* User authentication
* Backend database
* Order management system

## 🎯 Purpose

Luméra Skincare was developed to practice front-end web development, responsive design, JavaScript functionality, and modern e-commerce UI principles.
